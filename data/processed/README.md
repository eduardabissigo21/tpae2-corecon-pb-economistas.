# Dados processados

Esta pasta armazenará os dados tratados e organizados para análise do perfil e da inserção dos economistas no mercado de trabalho da Paraíba.

O tratamento poderá incluir padronização de variáveis, correção de inconsistências, organização de categorias e junção de bases compatíveis.

Os procedimentos realizados serão documentados para permitir a reprodução das análises.
