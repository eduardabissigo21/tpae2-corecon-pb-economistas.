# Notebooks do projeto

Esta pasta reunirá os notebooks e scripts utilizados no projeto sobre o perfil e a inserção dos economistas no mercado de trabalho da Paraíba.

Os procedimentos serão organizados em três etapas:

1. Aquisição dos dados: registro das fontes, links e métodos de obtenção.
2. Tratamento dos dados: organização, padronização e verificação de inconsistências.
3. Análise dos dados: produção de tabelas, gráficos e indicadores relacionados ao mercado de trabalho dos economistas.

Cada procedimento deverá ser documentado para facilitar sua reprodução pela equipe.
