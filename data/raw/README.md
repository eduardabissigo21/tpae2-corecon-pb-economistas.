# Dados brutos

Esta pasta será destinada aos dados originais utilizados no projeto sobre o perfil e a inserção dos economistas no mercado de trabalho da Paraíba.

Os dados serão obtidos de fontes oficiais, com registro dos links, das datas de acesso e das condições de utilização.

Arquivos restritos, dados pessoais ou informações confidenciais não serão armazenados neste repositório.
