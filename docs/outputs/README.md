# Resultados do projeto

Esta pasta será destinada aos produtos gerados durante a pesquisa sobre o perfil e a inserção dos economistas no mercado de trabalho da Paraíba.

Os resultados poderão incluir:

- Tabelas estatísticas;
- Gráficos e visualizações;
- Indicadores sobre o mercado de trabalho;
- Relatórios e outros produtos analíticos.

Os arquivos serão adicionados à medida que a equipe realizar a coleta, o tratamento e a análise dos dados.

Cada resultado deverá ter sua origem identificada e, quando aplicável, indicar o período de referência e o procedimento utilizado para sua produção.

Não serão incluídos dados pessoais ou informações cuja divulgação não seja permitida.
